# 表情包

把允许公开发送的 PNG、JPEG、GIF、WebP 图片放在这里。文件名只用中文、字母、数字、下划线或短横线，例如「开心.png」「嘴硬.webp」。文件名就是模型选择表情包时的含义提示。

所有会话统一使用此图库。人工素材放根目录，自动收藏放 `shared/`，其原生SQLite `index.db` 保存模型理解的画面、情绪含义、适用场景和关键词。QQ 的表情标记只作为识别线索，主模型看图后用 `learnStickers` 填写含义；微信收到的明确梗图同样可收藏。普通照片、证件和私人截图不自动当作公共表情。

自动字段收藏按内容哈希去重，使用 dsh-meme 的现有检索排序选择最多24张候选，主模型根据含义与当前聊天决定是否发送。图库中的表情可以从任何私聊或群聊发出。

旧的 `scopes/` 是迁移原件，运行 `node Harmonia/scripts/migrate-stickers.mjs` 可合并到共享图库；保留原件，不再按会话写入，重复迁移不会覆盖共享库中已修正的含义。旧shared/index.json也仅保留作迁移原件。临时下载仍在项目根 `.cache/harmonia/media`，不作为持久图库。

原生dsh-meme四项工具已全面启用，与桥接共用index.db。send_meme/meme_list返回的图库绝对路径可填进最终回复sticker字段，宿主检查索引和真实路径后发原生图片；meme_update直接修改同一索引，learn_meme收藏的图片下一轮即可选用。插件图库面板和图包市场沿用上游。
