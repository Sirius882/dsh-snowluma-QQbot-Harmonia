# 静默自启说明

手动整套控制入口现位于项目根：`E:\QQbot\start-all.bat`、`stop-all.bat`、`restart-all.bat`。关停脚本自动禁用拉起任务，启动/重启恢复自启；不需要先手动打开任务计划程序。整套关停包含全局DSH，会影响其他正在使用它的项目。

配置日期：2026-10-31。任务名：`Harmonia-Autostart`。

## 启动与恢复

- 当前 Windows 用户登录后延迟 30 秒运行；另有每 2 分钟执行的进程检查。
- 使用当前用户的交互会话、普通权限，不保存 Windows 密码。计划任务通过无控制台的 wscript.exe 入口，以窗口模式 0 启动 PowerShell；Node 子进程也显式隐藏。不打开浏览器、不主动生成二维码。
- 只在对应端口未监听时启动 SnowLuma 或 Harmonia；已经在线时不重复启动。
- 通过 SnowLuma 的已认证本机 API 选择 配置中 `BOT_QQ_ID` 指定的机器人 QQ；匹配不到或出现多个候选时不猜测、不载入主人账号。相同 PID 最多尝试载入三次。
- SnowLuma 的全进程自动载入被显式关闭，避免把主人 QQ 一并接入。微信凭证过期则保留需要登录的状态，不循环拉起登录窗口。

Windows QQ 已有系统自启项，使用 `/background`。如果 QQ 没有恢复小号登录，服务会等待；登录小号后，下一次检查自动接入。代理仍使用现有 `127.0.0.1:7897`，没有修改代理软件的系统设置。

这里的“开机自启”具体是**登录 Windows 后启动**，不是未登录 Windows 时在服务会话里运行 QQ。关机、睡眠或退出当前 Windows 会话后不能保证 bot 在线；登录凭证失效也不能靠自启绕过。

## 管理

在 Windows“任务计划程序 → 任务计划程序库”中查看 `Harmonia-Autostart`（它标记为隐藏，必要时开启“显示隐藏的任务”）。也可执行：

```powershell
Get-ScheduledTaskInfo -TaskName Harmonia-Autostart
Start-ScheduledTask -TaskName Harmonia-Autostart
Disable-ScheduledTask -TaskName Harmonia-Autostart
Enable-ScheduledTask -TaskName Harmonia-Autostart
```

禁用任务只停止后续自启与恢复，不会结束已经在运行的服务。人工停止服务前先禁用任务，否则下次检查会重新启动。

重新注册（例如移动目录后）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File E:\QQbot\Harmonia\scripts\install-autostart.ps1
```

安装脚本从自身位置解析工作目录，并记录当前 Node 可执行文件的绝对路径；升级或移动 Node 后重新注册。
