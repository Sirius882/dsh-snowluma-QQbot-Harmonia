# 聊天历史窗口

生效规则：四天、50条批量窗口，适用于QQ群、QQ/微信私聊和主动轮次。用户消息及bot每个文字泡分别计数，当前输入计入阈值。

## 批量裁剪

- 达到50条，一次移除最早30条。例如50条变20条；已有49条历史时，加当前输入会达到50，因此先移除30条历史，提供19条历史加当前输入。
- 以当前保留的最早记录为起点，经过四个完整24小时后，一次移除该起点开始的最早三个24小时。三天边界上的记录保留；若离线很久，重复裁剪直到最早记录不足四天。
- 两项规则都执行。消息按可靠时间排序；未知、无效或未来时间不注入。满四天的补发事件在下载、审核和主脑之前跳过；引用内容同样遵守时间限制。
- 输出多泡时，保存全部新输入和每个文字泡后再按同一规则裁剪。不会为了凑满50条重新填回已经移除的旧记录。
- 主人QQ/微信共用近期窗口，各群与访客分别保存近期窗口；长期记忆仍只有一份，来源不作为访问权限。

历史选择不修改原始数组。正常轮次把裁剪后的活动窗口写回runtime/sessions；部署切换时先做文本备份，再按同一规则归整既有活动窗口。原始DSH日志和历史备份保留，不清空会话、收据或去重状态。

## 管理员手动重置

主人在 QQ 或微信私聊发送 `/reset`；QQ群中由主人本轮直接 `@机器人 /reset`。只识别本条原始文本中的完整命令，大小写不敏感，可有首尾空白；引用、转发、图片及语音转写里的命令无效。访客和普通群成员没有重置权限，群管理员身份不自动获得权限。

命令由桥接直接执行，不调用主脑、群审核、媒体下载或表情收集，模型未就绪也可使用。先取消当前范围内正在处理和已排队的桥接轮次，再复用社区 qq-bridge 的 `NodeApiClient.stopSessionWork()` 清理 DSH inbox 和取消运行任务，最后清空该范围的近期历史。群聊同时停止普通群会话与主人 @ 会话；不会操作其他群或主人私聊。主人 QQ/微信私聊共用窗口，因此任一端重置同时影响两端。

保留原 DSH 会话 ID、权限、人设、长期记忆、原始日志、收据、主动消息绑定与投递配额。下一条消息从空近期窗口开始，仍按四天/50条规则累积；DSH 首步的历史遮蔽机制阻止旧日志自动重放。命令与确认回复不计入聊天历史。重置前已生成、尚未投递的主人主动候选作废，使用 `runtime/context-resets.json` 持久记录边界，已纳入文本备份。

重复事件不再次重置或打断新轮次，取消的轮次不写回旧回复及模型返回的记忆。微信接收与推理解耦，持续轮询以接收 `/reset`，游标仍在对应批次处理结果落盘后按顺序提交。DSH 停止失败时保留近期历史并明确提示重置未完成，不假报成功、不自动重试。已发送的消息和工具已经完成的外部操作不能撤回。已派出的独立后台 Codex 工程任务目前没有会话归属登记，不在 `/reset` 的取消范围内，不能按进程名批量结束它们。

社区方案已核对：[qq-bridge 管理员命令](https://github.com/Derpyu520/qq-bridge/blob/main/RULES.md)、[现成停止任务客户端](https://github.com/Derpyu520/qq-bridge/blob/main/src/dsh-client.js)。直接复用项目固定版本中的客户端；未安装另一套 QQ 接入插件，未实现 `/new`。

## 阻止隐藏重放

DSH专属预设在新轮首步用原生surface replacement遮蔽上一轮及更早日志，模型只收到桥接提供的合规批量窗口。系统锚点和当前轮工具步骤保留，自动历史摘要停用；不自动重跑失败agent。其他DSH项目不套用此策略。

主动轮次使用同一批量选择函数读取近期主人聊天，不能绕过上限。旧资料到期或满条时集中裁剪，因此缓存会在批次边界重建，批次内部保持追加。

## 长期记忆

唯一权威文件为memory/memories.json，所有会话共用，由bot自由维护。四天/50条只影响近期聊天，不按此删除长期记忆。

请求使用runtime/memory-prompt.json派生的稳定快照和尾部增量：新增或状态变化即时写入权威文件、通过增量供模型使用；累计20条增量或达到8KiB时合并。原文修正、删除或遗忘立即重建，旧文本不继续进入下一轮。来源和条目id保留。快照不是第二份独立记忆，损坏或缺失可以从权威文件重建；详见请求缓存.md。

## 验证

测试覆盖49/50/79/80条边界、当前输入与多泡计数、四天前后和最早三天边界、离线后的多批裁剪、未知/未来记录排除、批次内部前缀稳定、各会话一致及DSH隐藏重放隔离。真实DSH集成检查实际请求和记忆快照/尾部增量，不向QQ或微信发送合成测试消息。
