# 普通文字回复与内部字段

2026-11-07 19:33:18的群内看图请求已经获得模型回答，但供应商返回普通文字，旧桥接强制按JSON解析，导致SyntaxError且未发送。现将DSH聊天正文改为直接普通文字，不再要求整段回复是JSON；主脑路由、专属系统提示、状态提示及当前话题续接同步采用同一约定。

普通文字整体作为一泡，不按空格、标点或段落切分。需要显式多泡、图片、文件、记忆、来源、潜水或内部状态时，在正文后追加专用内部块。例如：

````text
这是直接发送的正文。
```harmonia
{"sticker":"图库标识或路径","facts":["一条完整记忆"],"aliveUpdate":{},"tsundereUpdate":{"k":0.3,"delta":0}}
```
````

- 内部块不会发送给用户；没有额外字段时可完全不写。主人私聊的逐轮状态评估仍通过内部块提交，独立沉默评估仍使用状态JSON。
- 可在内部块提供显式`bubbles`数组替代正文，或以`reply:false`潜水。纯正文沿用每泡3800字符限制，多泡沿用最多8条的限制。
- 内部块未闭合、JSON损坏或不是对象时，整块丢弃，仅发送已经完整的正文；不猜补、不读取其中半截路径/记忆/状态。无正文且内部块损坏仍失败。完整但类型错误的字段继续由原校验器拒绝。
- 纯文字不推断本机路径、附件、记忆或状态；结构化字段继续走附件权限、文件存在性、记忆来源、状态范围及投递去重校验。
- 仍兼容旧完整回复JSON及下文的尾部截断恢复；疑似损坏的旧JSON或夹带内部字段的混合输出不会当普通文字直接发出，防止泄露内部字段。
- 不修改PERSONA.md、全局模型/提供商配置及失败收据，不补发旧消息。工具参数、Terra审核、内部沉默评估和HTTP/SSE协议解析继续保持原约束。

## 兼容旧回复 JSON

2026-11-07。两次 QQ 私聊失败均为供应商返回 HTTP 200、Responses `completed`，但聊天 JSON 在 `aliveUpdate` 中间结束。2026-11-07 08:36:08 和 08:51:43（北京时间）的原始回复分别有完整的4泡、3泡聊天正文，桥接原先在 JSON.parse 抛出 SyntaxError，因而发送通用失败通知。

09:01:34收到的私聊是另一种情况：09:02:47模型输出完整合法JSON，包含3泡bubbles、sticker和aliveUpdate，但省略reply及空记忆数组。共享validateReply现对缺失的sticker/facts/todos/slang/impressions补空值；仅在完整bubbles数组及实际文字/媒体声明存在时，允许省略reply并按true处理。显式reply=false保持不回复，显式错误类型、缺少bubbles或空对象仍拒绝，不用默认值覆盖已经返回的错误字段。

`lib/reply-json.mjs` 作为共享接收入口，由 `brain/dsh.mjs` 的 `parseDshReply` 及 dsh-alive 主动回复适配器调用。正常 JSON 直接解析，完整或未闭合的 Markdown JSON 代码围栏可移除；严格解析失败时，复用本机 DSH Web profile 已安装的 `@deepseek-ai/dsh-util-values` / `PartialArguments` 读取完整顶层字段，没有增加 npm 依赖或另调模型修复。

- `reply` 必须是完整布尔值，`bubbles` 必须是完整数组。reply=true 时必须保留实际文字或完整媒体声明，不能把空输出冒充回复成功。
- 保留完整字符串、数组、对象和标量。未闭合字段整项丢弃；不猜补半句正文、文件路径、记忆或状态。一个 `aliveUpdate` 内已有完整 mood，但后面的 intent/loops 被截断时，整个 `aliveUpdate` 都丢弃。
- 缺失或被截断的 sticker 默认为空串，facts/todos/slang/impressions 默认为空数组；其他可选字段继续沿用现有校验器的空值默认。已经完整输出但类型错误的字段不会被替换成默认值。
- 恢复后仍调用 `validateReply`，原有分泡/大小限制、附件权限、路径存在性、记忆来源及投递去重继续执行。完整记忆走正常保存流程，完整状态更新走原有语义校验；不完整状态不生效。
- 段内语法已坏、主 JSON 前后有额外文字、bubbles 本身未写完、缺少 reply 或恢复文本大于1Mi字符时继续拒绝。此补丁针对尾部截断，不做任意格式改写。

普通私聊、群聊及主动候选共用解析；顺带状态评估读取完整 aliveUpdate 时也使用同一解析器，随后沿用 assessmentChanges 的范围和类别校验。独立沉默评估、Terra 审核、工具调用参数及整个 HTTP/SSE 协议包未放宽；网络失败、DSH error/aborted 终态仍失败，不根据半截网络回复执行工具或补发聊天。

原始 `chatlog` 和 DSH 会话日志保持模型原文。恢复时应用诊断只记录完整字段数量，不打印聊天、记忆或密钥。已失败的旧收据保持原状，不自动重试或补发。手工恢复旧记忆不在本补丁自动执行范围内。

测试包括两次真实抓取结果的离线回放（仅检查、不发送）、截断字段与转义字符、非法完整字段、私聊记忆和回执去重、主动候选与状态应用，以及独立 DSH HOME＋本机假模型的 Chat Completions/Responses 原始截断 JSON。修改桥接与 DSH 插件后需在共享服务空闲时用原服务入口重启加载。
