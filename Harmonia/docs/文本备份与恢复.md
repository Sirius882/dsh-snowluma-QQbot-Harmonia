# 人设与记忆文本备份

备份目录：`D:\Backup\QQbot`。Windows 任务 `Harmonia-TextBackup` 每小时运行一次，当前用户登录后延迟一分钟也运行；错过时在可运行后补跑。静默运行，不依赖 Codex、DSH 或 bot 在线，停止 bot 不会停止备份。电脑关机或用户未登录时不会运行。

`CURRENT.txt` 写明最新完整快照目录，`last-run.json` 记录最近成功检查时间、文件数与快照位置。快照在 `snapshots\时间戳\`，内部沿用原目录结构，文本可以直接打开。

## 范围

- `Harmonia/config/` 下的 Markdown、TXT，包含唯一人设 `PERSONA.md`。
- `Harmonia/memory/` 全部 Markdown、TXT、JSON、YAML、TOML 文档，包含长期记忆、群印象、信源与兴趣。
- `Harmonia/runtime/sessions/` 最近聊天记录，以及 DSH 会话映射、主动调度映射和派生记忆快照/增量状态memory-prompt.json（存在时）。派生状态缺失可由权威memories.json重新生成。
- `Harmonia/docs/`、`Harmonia/VALIDATION.md`、项目根 Markdown/TXT、`旧bot人设文档/` 的上述文本格式。
- 此备份脚本、安装脚本和静默启动器，方便重新部署备份任务。

不含 `.env`、登录凭证、密钥、vendor、媒体、缓存、数据库或全局 DSH 压缩会话档案。这是人设/记忆文本备份，不是整套 bot 和完整 DSH 历史的系统镜像。备份包含私聊与私人记忆，应像原文件一样保管。

## 保存与检查

源文件集合或内容有变化时创建完整新快照，无变化只更新时间。每份文件校验 SHA-256，全部成功后才写入 `manifest.json`；没有清单的目录视为未完成。旧快照不自动删除；误删源文件也不会删除此前快照。必要人设/长期记忆缺失、JSON 无效或写盘校验失败时任务报错，已有快照保留。

文件在 bot 运行时逐份读取，不承诺所有文档来自同一个事务时刻。每小时备份可能丢失两次运行之间的最新修改。备份位于另一盘符，仍无法防御整机损坏或所有磁盘同时受影响。

运行备份：

```powershell
node E:\QQbot\Harmonia\scripts\backup-text.mjs
```

重装/更新定时任务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File E:\QQbot\Harmonia\scripts\install-text-backup.ps1
```

检查任务结果：

```powershell
Get-ScheduledTaskInfo -TaskName Harmonia-TextBackup
Get-Content D:\Backup\QQbot\last-run.json
```

`LastTaskResult=0` 表示最近任务成功。失败细节在 `E:\QQbot\.cache\harmonia\text-backup-error.log`；清空 `.cache` 不会删除备份、任务或可复用脚本，下次运行会重建所需缓存目录。

## 恢复

先暂停相关写入（运行 `E:\QQbot\stop-all.bat` 可停止 bot），保留当前损坏或误改文件。从 `CURRENT.txt` 指向的快照，或误改发生前的旧快照，按相同相对路径复制所需文件回 `E:\QQbot`，再启动 bot。唯一生效的长期记忆是 `memory/memories.json`，恢复时一并检查所选快照中的最近聊天记录，避免新旧内容矛盾。旧主人/群记忆及信源原件已合并并归档到 `memory/legacy/`，不要把它们重新当作独立生效记忆。不需要全量覆盖整个项目，也不要把旧的 DSH 会话映射盲目用于另一套 DSH 安装。
